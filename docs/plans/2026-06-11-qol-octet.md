# QoL Octet (Features 17–24) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship roadmap 17–24 in one batch: backup/restore, duplicate-upload guard, per-car fuel price, drag-and-drop, retry-failed, history search, spend-by-tag, PWA.

**Architecture & behaviours:** authoritative in `docs/specs/2026-06-11-qol-octet-design.md`. All
client-side. TDD per feature, one commit each, ordered by shared-file dependency (the batch loop in
`App.tsx` is touched by 19→18→21 in sequence; HistoryView by 22→23; PWA last since it changes the
build).

**Tech Stack:** React + TS, Vitest + RTL, fake-indexeddb, vite-plugin-pwa (new dev dep).

### Task 1 (#19): per-car fuel price
- `history/types.ts`: `pricePerL?: string` on `Car`. `db.ts`: `patchCar(vin, patch)`; `touchCar`
  delegates. `App.tsx`: car-select handler fills the €/L input from the car record (No car →
  localStorage); after a successful batch, persist a valid price via `patchCar`.
- Tests: `db.test.ts` patchCar; `App.test.tsx` price saved + filled.
- Commit: `feat(garage): per-car fuel price memory`

### Task 2 (#18): duplicate-upload guard
- `BatchProgress.tsx`: `skipped` status (`—` icon, "skipped · already in history", settled includes
  skips, summary `· N skipped`). `App.tsx` loop: pre-check `parseDriveDate(file.name)` against
  history driveDates + this batch's processed dates; end-of-batch rules per spec.
- Tests: `BatchProgress.test.tsx` skipped row/summary; `App.test.tsx` duplicate filename → skipped,
  single history row, no error.
- Commit: `feat(progress): skip duplicate uploads (same recording date already in history)`

### Task 3 (#21): retry failed
- `App.tsx`: extract `analyzeFiles(list)`, keep batch `File[]` in a ref; `retryFailed()` re-runs
  failed files only. `BatchProgress.tsx`: optional `onRetry`, `Retry failed (N)` pill when settled
  with failures.
- Tests: `BatchProgress.test.tsx` button gating + callback; `App.test.tsx` retry refetches only the
  failed file and the summary updates.
- Commit: `feat(progress): retry failed files`

### Task 4 (#17): backup & restore
- `db.ts`: `exportAll` / `importAll` per spec. `PrivacyOverlay.tsx`: backup row (Download backup /
  Restore backup file input / status line). `App.tsx`: blob download + restore handler.
- Tests: `db.test.ts` round-trip + junk rejection; `PrivacyOverlay.test.tsx` buttons + status;
  `App.test.tsx` restore refreshes history.
- Commit: `feat(history): backup & restore (JSON export/import)`

### Task 5 (#20): drag-and-drop
- New `src/dnd.ts` `filesFromDrop` (entries traversal, folder support, .csv filter, dt.files
  fallback) + `dnd.test.ts` with faked entries. `Uploader.tsx`: drop zone + `upload--drag` CSS.
- Commit: `feat(upload): drag-and-drop CSVs (folders supported)`

### Task 6 (#22): history text search
- `history/tags.ts`: `searchDrives` + tests. `HistoryView.tsx`: search input feeding `shown`.
- Commit: `feat(history): text search across label, notes, tags`

### Task 7 (#23): spend-by-tag
- New `TagSpend.tsx` (+test) per spec; rendered after PeriodSummary with `shown`.
- Commit: `feat(history): spend-by-tag card`

### Task 8 (#24): PWA

- Verify: `npm run build` emits `dist/sw.js`; full suite green.
- Commit: `feat(pwa): installable app shell with offline support`
